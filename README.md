# Röst

Röst is a third-party iOS app for the open source [Audiobookshelf](https://github.com/advplyr/audiobookshelf) project.

[![Dowload on the App Store](https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg)](https://apps.apple.com/us/app/r%C3%B6st/id6739761060)

## Platforms

- iOS
- iPadOS
- macOS

## Deployment Target

Base deployment target: iOS 26.0.
